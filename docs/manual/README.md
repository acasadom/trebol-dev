# The Trebol designer: user manual

The designer lets you build the screens of a Trebol program with the mouse: you add faces from a menu, choose
them, set what they say and how they behave, and see the result at once. Everything you do becomes Trebol code
in your file, written as a person would write it, so you can go on by hand whenever you like.

The manual is a walk through one small project. Each chapter builds on the one before; read them in order the
first time, and come back to any of them later.

1. [The window](01-the-window.md): starting the designer and what each part of the window is for.
2. [Your first screen](02-first-screen.md): a contact form made from an empty view, step by step.
3. [Properties](03-properties.md): what a face says, the word code knows it by, and every option its style takes.
4. [Events](04-events.md): what a button does when it is clicked, and the code that runs on other events.
5. [Screens, tabs, steps and rows](05-screens-tabs-rows.md): an app with more than one screen.
6. [Styles of your own](06-styles-of-your-own.md): the styles a file defines, in the *Add* menu.
7. [The code](07-the-code.md): working by hand next to the design, problems, and saving.

You need [Node.js](https://nodejs.org/) 22.18 or later. Knowing Trebol helps, but is not needed to start: the
[UI tutorial](https://trebol-lang.com/docs/) explains what each face is, and the designer shows the code each
change makes, so you learn the language as you go.
